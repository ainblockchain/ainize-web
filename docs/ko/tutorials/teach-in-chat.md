# 대화로 가르치기

[라이브 테스트](https://ainize.ai/chat?teach=1)를 엽니다. 호환 서빙 런타임·패치 훅·활성화된 가르치기가
필요합니다. 노드 정책은 [가르치기](https://ainize.ai/teach)에서 확인하세요.

## 수정하고 모으기

1. 가르치기 키를 만들거나 가져온 뒤 백업을 다운로드합니다. 이 키가 수업을 소유합니다.
2. 짧은 사실 질문을 하고, 답이 틀리면 정답을 입력합니다.
3. 다른 표현의 질문도 추가하면 학습한 내용을 바꿔 물어도 답하는지 확인할 수 있습니다.
4. 수업 바구니에서 오류와 개인정보를 제거합니다.
5. 학습 강도를 선택하고 제출한 뒤 진행 상태를 확인합니다.

행 수·일일 제출·대기열 한도는 노드마다 다릅니다. 브라우저 키를 유지하세요.
[내 데이터셋과 수업](https://ainize.ai/teach/mine)이 이 키로 작업을 찾습니다.

## 결과 확인

정확도·무관 질문 검사·해당하는 경우 부모 지식 회귀 검사를 확인합니다.
실패하거나 불완전한 수업을 성공한 결과로 공개하면 안 됩니다. 비공개로 유지하거나,
`READY` 수업의 권리·라이선스·가격·영구 공개 동의를 검토한 뒤 공개하세요.

브라우저에서 받은 키로 CLI에서도 같은 수업을 확인할 수 있습니다.

```bash
ainize teach status "https://ainize.ai/teach/lesson/<lesson-id>" --key-file ./teaching-key.json
```

파일 업로드와 CLI 공개는 [파일로 가르치기](./teach-from-a-file.md)를 참고하세요.

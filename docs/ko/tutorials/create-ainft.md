# 지갑에서 사용할 AINFT 에이전트 만들기

Ainize에서 에이전트를 만들고 네이티브 AINFT로 등록하면 AIN Wallet에서 열어 대화하거나 작업을 맡길 수 있습니다.

## 1. 지갑과 네트워크 선택

AIN Wallet을 설치하고 잠금을 해제합니다. 토큰을 만들 계정을 선택하세요. 처음에는 **TestNet**으로 시작하고, 필요한 테스트 AIN은 [Faucet](https://faucet.ainetwork.ai/)에서 받습니다. 등록을 마칠 때까지 같은 계정과 네트워크를 유지하세요.

이미 AINFT를 가지고 있다면 먼저 선택한 계정과 네트워크를 확인하세요. MainNet 토큰은 TestNet 목록에 표시되지 않습니다.

## 2. Ainize에서 에이전트 만들기

[Ainize 에이전트](https://ainize.ai/agents)를 열고 로그인한 뒤 에이전트를 만듭니다. 이름과 설명을 입력하세요. 처음에는 prompt 모드에서 사용 가능한 모델을 고르고, 어떤 도움을 줄지 적어 시작할 수 있습니다. 저장한 뒤 준비 완료 상태가 될 때까지 기다립니다.

만든 계정으로 로그인한 상태에서 에이전트 상세 페이지를 여세요. 다른 실행 방식은 [에이전트 호스팅](../how-to/host-an-agent.md)을 참고하세요.

## 3. AINFT로 등록

에이전트 상세의 **AINFT로 등록**에서 **지갑으로 등록**을 누릅니다. 새 토큰을 만들 때는 **기존 AINFT 연결**을 선택하지 않습니다.

AIN Wallet에 표시되는 계정 연결, 서명, 트랜잭션을 확인하고 승인합니다. 컬렉션 준비, 토큰 민팅, 이름·이미지·에이전트 링크 공개, 지갑 검색 확인 순서로 진행됩니다. 등록이 끝날 때까지 페이지를 열어 두세요.

도중에 중단되면 같은 계정과 네트워크로 돌아와 **등록 상태 확인·계속**을 누릅니다. 저장된 등록을 이어서 확인하므로, 응답이 늦다고 다른 에이전트를 새로 만들 필요는 없습니다.

기존 토큰에 연결하려면 **기존 AINFT 연결**을 선택하고 컬렉션 주소와 토큰 ID를 입력합니다. 선택한 지갑이 컬렉션 관리자여야 하며, 현재 토큰 보유자의 소유권은 유지됩니다.

## 4. AIN Wallet에서 확인

등록 화면에 표시된 보유 계정과 같은 네트워크로 지갑의 **AINFT** 탭을 엽니다. 컬렉션과 토큰을 선택하면 이름·이미지·설명이 표시됩니다.

**Open Ainize agent**로 공개 페이지를 열거나 **AINA에서 대화**로 AINA 패널을 통해 엽니다. 토큰을 가진 지갑으로 로그인한 뒤 내 작업 공간을 여세요.

목록에 없다면 계정과 네트워크를 확인하고 AINFT 탭을 다시 연 뒤 등록 상태를 확인합니다. 목록 조회 실패는 빈 지갑과 별도로 오류로 표시됩니다.

## 5. 대화·작업·기억 활용

질문하거나 작업을 맡기고 완료된 결과를 확인하세요. 유용한 정보는 개인 기억으로 저장하고 승인해야 이후 답변에 활용됩니다. 대화와 기억은 지갑별로 비공개이며, 모델 재학습은 필요하지 않습니다.

AINFT를 양도하면 새 보유자는 자신의 작업 공간을 사용하고 이전 보유자는 접근할 수 없습니다. 이전 보유자의 개인 대화와 기억이 함께 양도되지는 않습니다.
